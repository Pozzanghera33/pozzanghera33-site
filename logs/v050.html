SYSTEM CRITICAL

⚙️ Important System Changes & Security Fixes

🔧 Save Directory Migration for Options Settings

We have officially changed the internal saving path for all custom configuration and option settings to the system's local PersistentDataPath directory:
AppData -> Local Low -> POZZANGHERA 33 -> [DEAD BEFORE WORK THE COMMUTE]
*Why we did this:* In our previous build, certain strict PC administrative layouts or automated anti-virus software caused sudden security blocks, occasionally preventing option settings from being written to disk. Shifting this data to the global OS application default standard path permanently resolves this issue.

🚨 ATTENTION DESIGNERS: Custom MapData Export / Save Issues?

If you notice that your custom map data files are failing to export properly, or if clicking the save functions yields no response, it is highly likely that your active Windows Security / Windows Defender parameters are aggressively blocking the game executable from creating raw file strings on your drive.

How to Fix: You can instantly bypass this administrative restriction and restore full saving functionality by choosing and updating your Map Data output directory folder to the universal, unrestricted default application path mentioned above.
