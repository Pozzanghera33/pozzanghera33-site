--- HOW TO WORK THE CREATOR ARCHITECTURE ---

CREATOR IDENTITY

🏷️ Set Your Creator Handle Name!

Before exporting your evil masterpieces, make sure to create and save your personalized name using the Creator Name Generator located at the bottom-right of the title screen!

This name will be stamped forever as the author metadata on any map you design in Creator Mode. Please input a 3-digit number in the numeric blank field to uniquely identify yourself among world-class trap architects!


MAP ARCHITECTURE

💾 Saving & Exporting Your Masterpieces

Placing traps and decorative elements consumes Memory. If you run out of space, don't worry—the maximum memory threshold can be permanently expanded by purchasing upgrades in the Trap Shop!

The Golden Rule of Architecture: In order to export and save your map, you must first do a test play and successfully clear it yourself! You have to prove that your hellish creation is actually beatable. Once you clear it, type your map's name into the bottom-right text field and hit the 【Export】 button to save it.

If you wish to change your save location, you can choose any custom directory via the folder selection button.

⚠️ Safety Lock Warning: If you make even a single change to your map after clearing it, the system resets your "proven status," and you must clear it once again before exporting. (We designed this to guarantee all shared maps are 100% possible to beat!)

MAP ARCHITECTURE

📂 Loading Saved Maps

Loading your custom levels is instant. Simply type the exact filename into the text box on the bottom-right and press the 【Load】 button to jump back into editing or testing.

※ Caution: Loading a level will instantly overwrite whatever unsaved work you are currently editing, so save often!

When scanning for maps, the game looks strictly inside the folder you currently have selected. If you want to load an older file created before you changed directories, either switch back to the original folder path or manually copy/move the file into your current active folder.

PLAY GUIDE

🎮 How to Play User-Created Maps

To dive into custom stages, select 【Play】 -> 【Custom Map】 from the menu. If your custom map directory folder is properly set, all available maps will appear instantly in a clean listview.
*Note: The game automatically references the specific directory path you specified during your map creation sessions.*

👥 How to Import Friend & Rival Maps

Want to test your skills against maps built by your friends or online rivals? Simply get their .poz33 map data file and drop it directly into your custom folder.

Alternatively, they can open their map file with any standard text editor (like Notepad), copy the raw text code string, and send it straight to you! Once you have the code, paste it completely into the blank input box at the bottom of the screen:

  • Left Button (Save File): Converts the pasted code into a permanent file on your drive, allowing you to load and play it whenever you want!
  • Right Button 【Direct Play】: Instantly fires up the level for a one-off challenge without saving it. Perfect for a quick, brutal test of your reflexes!

※ Double-Check Your Strings: When copying and pasting, make sure the text string hasn't been cut short due to length limits. If the code string is incomplete, the system will throw a loading error.
